# Motteta

「この本、持ってた…」に、買う前に気づくためのアプリです。

購入履歴と手持ちの本を一つの**台帳**にまとめ、Chromeの商品ページで、すでに記録がある本かどうかを確認できます。
紙の本と電子書籍を区別して記録するので、別の購入先や別の形態で持っている本を探すときにも使えます。

本の登録や履歴の取り込みは、Codexに日本語で依頼します。
買う前の確認はMottetaの拡張機能が行うため、そのつどCodexやターミナルを起動する必要はありません。

## できること

- 購入履歴を取り込み、購入先をまたいでまとめる。
- 実店舗で買った本や、購入日を覚えていない手持ちの本を登録する。
- 商品ページで登録済みの本や、同じ本かもしれない候補を表示する。
- 書名や著者名から、登録した本を検索する。
- 購入日、紙と電子の区別、返品や現在の所持状態を確認し、後から訂正する。
- 台帳をバックアップし、必要に応じて復元する。

## 使い始めるまで

現在の利用環境は **macOSとChrome** です。
登録にはサブスクリプションで利用するCodexを使い、購入履歴の取り込みにはCodexのブラウザ操作機能も使います。
Motteta用のAPIキーは不要です。

1. [初期設定の手順](docs/setup.md)に沿って、台帳とChrome拡張機能を用意します。
2. まず手持ちの本を一冊登録するか、購入履歴の一部を取り込みます。
3. 対応する商品ページを開き、書名付近の「Motteta：…」を確認します。

初期設定にはターミナルを使います。
設定後は、以下の依頼例とChromeの商品ページから利用できます。

## 手持ちの本を登録する

CodexでMottetaのリポジトリのフォルダーを開き、次のように依頼します。
「書名」の部分を登録したい本に置き換えてください。

```text
$motteta-register を使って、次の本を所持記録として登録してください。

書名：ここに登録したい本の書名を書く
紙の本を1冊持っています。購入日と購入先は不明です。
```

書名の代わりに商品URLを渡しても登録できます。
ISBNを自分で調べる必要はありません。
Codexが書名やURLから情報を確認し、特定できないISBN、版、購入日などは不明のまま残します。

新しく買った本なら、分かる範囲で購入先や購入日も伝えてください。
以前から持っている本は、登録した日を購入日として扱いません。
保存先も、変更したい場合を除いて指定不要です。

## 買う前に商品ページで確認する

Chromeで、買おうとしている本の商品詳細ページを開きます。
書名の近くに、次のような判定が表示されます。

```text
Motteta：記録あり
```

| 表示 | 意味 |
| --- | --- |
| 記録あり | 同じ本として照合できた購入や所持の記録があります。 |
| 同じ本の可能性あり | 候補はありますが、同じ本かどうかを確定できていません。 |
| 記録なし | 台帳に該当する記録が見つかりません。 |

詳しく見るには、ChromeのツールバーにあるMottetaのアイコンをクリックします。
アイコンが見当たらない場合は、拡張機能の一覧（パズルのアイコン）からMottetaを開いてください。
ポップアップで、登録した本の書名、紙か電子か、購入先、購入日、冊数、注文や所持の状態を確認できます。

「記録あり」には、返品済みや手放した本の記録も含まれます。
いま手元にあるかどうかは、ポップアップの所持状態で確認してください。
紙の商品ページで電子版の記録が候補に出る場合もあるため、形態も合わせて確認します。

**「記録なし」は、持っていないことの保証ではありません。**
まだ登録していない本は、判定の対象になりません。
購入履歴の取り込みに抜けがないかも確認してください。
「確認できません」と表示された場合は、読み取りや接続に問題があるため、ポップアップで理由を確認してください。

## 購入履歴をまとめて取り込む

本を一冊ずつ登録する代わりに、Codexへ購入先と対象期間を伝えるだけで履歴を取り込めます。
例えば、次のように依頼します。

```text
$motteta-import を使って、楽天の直近1か月の書籍の購入履歴を台帳に取り込んでください。
```

「楽天」と指定した場合は、楽天ブックスと楽天市場の書籍の購入履歴を対象にします。
楽天Koboは取り込み対象に含めません。

履歴ページを事前に開く必要はありません。
Codexが接続済みのChromeで購入先を開き、履歴ページへ移動して、登録データの作成、既存記録との照合、取り込みまで進めます。
別のブラウザを指定したい場合や、紙だけ、電子だけに絞りたい場合は、その条件を添えます。

ログインや追加認証、ブラウザの利用許可が必要になった場合だけ、案内に沿って操作してください。
複数のアカウントなどで対象を決められない場合は、Codexから確認します。
通常は、保存先やアカウントの識別名を指定する必要はありません。
購入履歴を読むCodexのブラウザ操作機能と、商品ページに判定を出すMotteta拡張機能は別のものです。

数量が不明な本は既定で1冊とし、分かっている数量はそのまま使います。
別の扱いを希望する場合だけ伝えてください。
ISBNや購入日など、確認できない情報は不明のまま残します。
これらの共通の扱いを、依頼のたびに書く必要はありません。

取り込みが終わると、Codexが保存された件数、確認が必要な記録、未確認の範囲を報告します。
取り込みや調査に使った作業用タブは、終了時にCodexが閉じます。
途中で止まった場合は、同じチャットで続きを依頼できます。
購入履歴から同じ購入を識別できた場合は再取得でも既存の記録へ反映し、識別できないものは確認対象として残します。

**購入履歴は自動では更新されません。**
新しい購入を反映したいときは、前回以降の期間を指定して再び取り込みを依頼してください。
商品ページを開くだけでは、購入記録は追加されません。

## 登録した本を探す、記録を直す

商品ページを開かずに調べるときも、Mottetaのリポジトリを開いたCodexへ依頼できます。

```text
Mottetaの台帳で「調べたい書名」を検索し、購入先と紙か電子かを教えてください。
```

本を手放した場合や、登録内容を直したい場合は、登録用スキルへ対象と変更内容を伝えます。

```text
$motteta-register を使って、「書名」の紙の本の記録を探し、
所持状態を「手放した」に訂正してください。
```

「確認対象」は、同じ本かどうかや、同じ購入を取得し直したものかどうかを自動で決められなかった記録です。
Codexに候補と判断が必要な点を説明させ、確認できた内容に基づいて確定や訂正を依頼してください。

## 対応する商品ページと購入先

商品ページでの自動照合の対象は、Amazon.co.jp、楽天ブックス、楽天市場の書籍ページです。
楽天市場は商品情報を読み取れるショップのページに限られ、サイトの画面構造によっては照合できないことがあります。
検索結果一覧、カート、スマートフォンへの表示には対応していません。

台帳には、実店舗やその他の電子書籍サービスで買った本も登録できます。
商品ページでの自動照合への対応と、購入先として記録できることは別です。

## 保存先とバックアップ

台帳はMac内の次の場所に保存されます。
通常の利用で、このパスを依頼文へ書く必要はありません。

```text
~/Library/Application Support/motteta/ledger.sqlite3
```

購入時の照合には、このローカルの台帳を使います。
Codexに履歴取得や登録を依頼した場合は、Codexが読んだ情報はCodexの処理対象になります。
台帳自体の暗号化やクラウド同期は提供していません。

バックアップ、復元、接続の問題への対処は[保存とトラブル対処](docs/operations.md)を参照してください。
