# SEshopの履歴取得

対象は [SEshop](https://www.seshop.com/) で購入した紙の本と電子書籍です。
既存の購入先IDを再利用し、初めて登録する場合は `source.id: seshop`、`source.name: SEshop`、`source.kind: online` とします。

## 会員メニューから履歴を開く

1. 接続済みのChromeでSEshopを開き、ログイン後の会員メニューへ進みます。画面の案内は[会員メニューの説明](https://www.seshop.com/help/detail/h217)を参照してください。
2. 「注文履歴」と「発送前のご注文」または「現在ご注文中の注文」を確認します。画面の案内は[購入履歴の説明](https://www.seshop.com/help/detail/h220)を参照してください。
3. 電子書籍は「ご購入電子書籍およびデータダウンロード一覧」も確認します。画面の案内は[電子書籍の説明](https://www.seshop.com/help/detail/h345)を参照してください。

## 記録する内容

| 項目 | 読み取り方 |
| --- | --- |
| 注文と明細 | 注文番号、明細固有のID、対象の書名と数量を対応付けます。 |
| 購入日 | 注文日など、入手の日付として確認できる値を使います。 |
| 紙と電子 | 注文した商品の表示で確認します。PDF版は `book.format: digital`、確認できた形式は `file_formats: ["pdf"]` とします。 |
| 状態 | 注文状態と現在の所持状態をそれぞれ確認して記録します。 |
| 根拠 | 注文履歴は `purchase_history`、購入済み電子書籍の一覧は `owned_list` として、参照先と観測日時を残します。 |

商品URLの `/product/detail/` の後のIDは、`book.identifiers` に `namespace: seshop`、`scope: seshop.com` として保存します。
紙版とPDF版にはそれぞれ別の商品URLがあるため、実際に購入した形態のページを使います。

注文履歴を入手記録の主な根拠とし、電子書籍一覧は同じ購入の書名、形態、利用可能な形式を補うために使います。
購入済み一覧しか確認できない本は、共通の入手識別と期間の規則に従います。

## 重複とセット商品の扱い

入手の識別と再取り込みは[共通の手順](../collection.md#入手の識別と再取り込み)に従います。
注文履歴で取り込み済みの購入には同じ外部キーを使い、電子書籍一覧で見つけた追加のIDは根拠の注記へ残します。

紙と電子のセットでは、セットの商品ID、個別書籍、ダウンロード一覧の対応を確認します。
一明細が両形態を含む場合は、対応関係を未確認箇所へ記録して他の明細を取り込みます。
