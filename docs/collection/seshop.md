# SEshopの履歴取得

対象は [SEshop](https://www.seshop.com/) で購入した紙の本と電子書籍です。
書籍以外のイベント、講座、調査データなどは、書籍の取り込みに含めません。
既存の購入先IDを再利用し、初めて登録する場合は `source.id: seshop`、`source.name: SEshop`、`source.kind: online` とします。

## 会員メニューから履歴を開く

1. Codexが接続済みのChromeでSEshopを開き、ログイン後の会員メニューへ進みます。ログインが必要な場合だけ利用者へ操作を案内します。
2. 「注文履歴」と「発送前のご注文」または「現在ご注文中の注文」を確認します。公式の[会員メニューの説明](https://www.seshop.com/help/detail/h217)と[購入履歴の説明](https://www.seshop.com/help/detail/h220)では、発送前と発送後の注文を別の画面で扱っています。
3. 電子書籍は「ご購入電子書籍およびデータダウンロード一覧」に相当する画面も確認します。公式の[電子書籍の説明](https://www.seshop.com/help/detail/h345)では、この一覧から購入済みのPDF版を取得できることが案内されています。

注文の詳細を読む操作と、キャンセル、領収書の出力、注文内容の変更を分けます。
履歴の取得では後者を実行しません。
電子書籍のファイル本体の取得も不要です。
表示名やリンク先が変わっている場合は、現在の画面で対応する読み取り先を確認します。

## 記録する内容

| 項目 | 読み取り方 |
| --- | --- |
| 注文と明細 | 注文番号、明細固有のID、対象の書名と数量を対応付けます。商品IDを明細IDへ転用しません。 |
| 購入日 | 注文日など、入手の日付として確認できる値を使います。発送日、ダウンロード日、発売日では補いません。 |
| 紙と電子 | 注文した商品の表示で確認します。PDF版は `book.format: digital`、確認できた形式は `file_formats: ["pdf"]` とします。 |
| 状態 | 画面で確認できる注文状態を記録します。発送済みという事実だけで現在の所持状態を所持にしません。 |
| 根拠 | 注文履歴は `purchase_history`、購入済み電子書籍の一覧は `owned_list` として、参照先と観測日時を残します。 |

商品URLの `/product/detail/` の後のIDは、`book.identifiers` に `namespace: seshop`、`scope: seshop.com` として保存します。
書誌欄の「商品番号」とは別の値であり、注文や明細のIDには使いません。
紙版とPDF版にはそれぞれ別の商品URLがあるため、実際に購入した形態のページを使います。

注文履歴を入手記録の主な根拠とし、電子書籍一覧は同じ購入の書名、形態、利用可能な形式を補うために使います。
両方に同じ本がある場合、別々の購入として取り込みません。
購入済み一覧しか確認できない本は、共通の入手識別と期間の規則に従います。

## 重複とセット商品の扱い

同じ注文と明細には、継続して同じ外部キーを使います。
注文番号と明細IDで識別できる新しい購入は、その組み合わせを使い、一覧側のIDは根拠の注記に残します。
この場合に `external.holding_id` も追加すると優先するキーが変わるため、同じ入力へ混在させません。
既存の記録が注文番号と明細IDで対応付けられている場合、電子書籍一覧で見つけた別のIDへキーを切り替えません。
追加の参照情報は根拠へ残し、同じ購入へ対応すると確認できない一覧項目を別購入として自動追加しません。
明細IDがなくても注文内の一意性を確認できる場合は、共通の `order_product_format_v1` の規則を使います。

紙と電子のセットでは、セットの商品ID、個別書籍、ダウンロード一覧の対応を確認します。
一つの明細を、根拠なく紙一冊と電子一冊の二購入へ分割しません。
一明細が両形態を含み、現在の一記録一形態の入力で正しく表せない場合は、対応関係を未確認箇所へ残して他の明細を取り込みます。
識別できていない構成品へ架空の明細IDを付けません。

PDFの再ダウンロードやデータの更新を、追加購入とは扱いません。
再取得の入口は公式の[再ダウンロードの説明](https://www.seshop.com/help/detail/h359)で確認できますが、取り込みで再取得を行う必要はありません。

発送前、発送後、電子書籍一覧の必要な範囲を確認できない場合は、取得範囲を一部完了として残します。
